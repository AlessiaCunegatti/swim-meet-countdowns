# Swimming Meet Countdown

A simple interactive website that counts down to a swimming meet selected by the user.

## Features
- Enter a meet name and date/time.
- Display a live countdown in days, hours, minutes, and seconds.
- Validate that the selected meet is in the future.
- Show a race-day message when the countdown reaches zero.
- Responsive layout for desktop and mobile screens.

## Built With
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter a meet name and a future date/time.
4. Select **Start countdown**.
